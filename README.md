## Стек

- Angular 21
- TypeScript 
- Ng-Zorro Ant Design
- RxJS 

## Запуск
Должен быть установлен Node.js
```bash
npm install

npm start
```

Приложение будет доступно на `http://localhost:4200`

## Что реализовано

- Компонент со списком пользователей
- Компонент с деталями о пользователе 
- Компонент с валидируемой формой создания/редактирования пользователя
- Стилизация при помощи NG-ZORRO
- Фильтрация по имени или email
- Пагинация на странице со списком пользователей
- CI/CD пайплайн с линтером и деплоем на GitHub Pages


Так как API не позволяет изменять данные на сервере, то результат некоторых запросов может быть не виден в приложении. Чтобы можно было увидеть, что POST, PUT и DELETE запросы проходят, я специально оставил в сервисе логирование таких запросов (сообщения можно увидеть в консоли)
